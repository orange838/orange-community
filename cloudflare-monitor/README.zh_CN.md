# 橙子社区监控看板

这个目录包含橙子社区的静态监控看板。

## 看板内容

看板汇总以下项目状态：

- API 健康状态
- Pages 域名
- D1 数据库使用情况
- HTTPS 状态
- Git 提交信息
- Turnstile 人机验证通过和失败统计

看板不会展示 API Token、Worker Secret、邮件服务密钥或其他凭据。

## 数据说明

看板数据包含服务状态、最近一次 Git 提交和最近 24 小时的人机验证统计。
敏感凭据不会写入看板数据。

资源状态表会列出当前监控范围内的 Pages 项目和网站地址，以及每个地址的 HTTPS 检查结果、
Worker 状态接口是否成功响应，以及 D1 数据库读取结果。Cloudflare 资源接入项说明
Worker 与 D1 的连接情况，不用于判断是否登录了 Cloudflare 控制台。
