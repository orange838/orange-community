# CSL 个人博客 - 橙子社区

欢迎来到 **橙子社区 (Orange Community)** 仓库！本项目是 CSL 个人博客及社区平台的官方代码库。

##  项目简介
本平台旨在打造一个集技术分享、个人随笔与社区互动于一体的现代化空间。项目采用前后端分离架构，旨在提供稳定、高效的社区服务。

## ️ 技术栈
- **后端**: Python (FastAPI / Flask)
- **前端**: Vue.js / React (待定)
- **数据库**: SQLite / PostgreSQL
